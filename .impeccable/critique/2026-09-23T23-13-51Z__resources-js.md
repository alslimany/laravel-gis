**Why it looks unlike the UI kit website:** Kit demos show full component density (Cards, Stats, navigation primitives, overlays) on untouched preset tokens. This app uses a thin subset, dual token aliases, and list CRUD composition—so it never reaches the “demo polish” even when colors vaguely rhyme with ocean cyan.

**Why it looks unlike Stitch:** Stitch is map-first, docked, 4–8px dense, JetBrains Mono telemetry, amber tertiary locks. Shipped UI is document-scrolling admin with generous padding and no spatial chrome.
